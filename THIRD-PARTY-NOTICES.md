StreamEmber Overlay - third-party notices
=========================================

The StreamEmber Overlay packages (StreamEmber.Overlay.GTAV / StreamEmber.Overlay.RDR2) include the following
third-party software. Their license texts are installed next to this file
(<game>\StreamEmber\Licenses\StreamEmber.Overlay.<GAME>\).

Chromium Embedded Framework (CEF)
  https://bitbucket.org/chromiumembedded/cef
  BSD 3-Clause license: CEF.LICENSE.txt
  Files: StreamEmber\Overlay\libcef.dll and the other CEF runtime files in StreamEmber\Overlay\.
  CEF contains Chromium and its third-party components; their notices are built into libcef.dll and listed by
  Chromium's credits page.

MinHook (RDR2 package only)
  https://github.com/TsudaKageyu/minhook
  BSD 2-Clause license: MinHook.LICENSE.txt
  Statically linked into StreamEmber.Overlay.RDR2.asi.

MHud
  https://github.com/StreamEmberPlatform/mhud
  MIT license: MHud.LICENSE.txt
  Files: StreamEmber\Overlay\ui\mhud\. Fonts and icons bundled with the kit are listed in
  StreamEmber\Overlay\ui\mhud\kit\LICENSES.md.

Script Hook V / Script Hook RDR2 (Alexander Blade) are not included; players install them from
http://www.dev-c.com/.
